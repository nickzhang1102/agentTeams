从问题到结论

一个平台，一支团队

六个模块覆盖「理解 — 组队 — 执行 — 沉淀」的完整闭环。

01

Leader 编排

需求评估、DAG 团队组建、批次执行与结果汇总由 Leader 全程自动推进，支持人工审核介入。

02

多智能体协作

批次内多专家并行调用工具与知识库，执行状态实时可见，SSE 流式推送全过程。

03

100+ 专家 Agent

医疗专科、商业角色、金融分析等领域专家开箱即用，也支持创建自己的专属 Agent。

04

知识图谱 GraphRAG

D3 图谱可视化、社区发现与向量检索结合，让回答有据可依，还能定位知识缺口。

05

组合包与模板

AgentPack 沉淀常用团队组合，工作流模板一键启动标准化流程，减少重复配置。

06

数据自主

全部数据留在自己的 PostgreSQL 中，LLM 凭证以根密钥加密存储，部署位置由你决定。

一次提问的旅程

四步编排，从需求到报告

你只负责提出问题；Leader 负责理解它、为它组建最合适的专家团队、盯完整个执行过程，并把所有结论汇成一份可追溯的报告。

01

需求评估

Leader 判断任务复杂度，必要时向你追问澄清，确定评估阈值与专家范围。

requirement_loop
02

团队组建

按优先级规则从 100+ 专家中选人，生成 DAG 执行计划，分批安排就位。

team_form_dag
03

并行执行

批次内多专家并行调用工具与知识库，SSE 实时推送思考与中间结果。

batch_executor
04

综合报告

汇总各专家结论生成结构化报告，每个观点都可下钻到对应的子任务与证据。

summarize

示意动画基于真实编排链路绘制；实际界面中的每一步都可以展开查看执行细节。

本地掌握数据

三步，在自己的主机上运行

提供 Docker Compose 一键部署，也支持源码方式本地开发。

01

克隆并配置

terminal — clone & init 
git clone https://github.com/nickzhang1102/agentTeams.git
cd agentTeams
cp backend/.env.example backend/.env
# 编辑 backend/.env：
# SECRET_KEY / JWT_SECRET_KEY / DATABASE_URL
02

启动服务

terminal — compose up 
docker compose up -d --build

包含 PostgreSQL 18、FastAPI 后端与 Nginx 前端三个服务；访问 http://localhost:8380。

03

初始化并上线

默认账号 admin / admin123——首次登录后请立即修改密码；随后在后台「LLM 模型」添加一个 OpenAI 兼容服务即可开始使用。医疗场景请先阅读免责声明。
